# AI Farm Simulation Planning

## Summary
### Flow Summary
ทีมเลือกไอเดียสำหรับงานแฮกของ Meta ระหว่างฟาร์มซิมกับไวฟบุ๊ค สุดท้ายเลือกไวฟบุ๊ค เน้นการพรีเซนต์และความไวรัล แล้วนัดลุยต่อวันเสาร์

### สองไอเดียที่เสนอ
- ฟาร์มซิม: มาร์คที่ใน Google Maps, ให้ AI วางผัง, แล้วทำ feasibility วนแก้จนคุ้มทุน
    - ต่อยอดเตรียมเอกสาร PDF ขอสินเชื่อให้เกษตรกรได้
    - ลองกับฟาร์มปูนิ่ม 16 ไร่ ได้ผลว่าต้องลง 25 ล้านบาท ไม่คืนทุนใน 10 ปี
- ไวฟบุ๊ค: ปุ่ม widget ข้างโพสต์อวด AI กดแล้วพิมพ์ prompt สั้นๆ เพื่อโคลนรูป วิดีโอ หรือแอปได้ทันที
- ข้อกังวลของไวฟบุ๊ค: อธิบายคอนเซ็ปต์ยาก ต้องใช้วิดีโอช่วย และ Meta อาจลอกไปทำเอง

### กติกาและทรัพยากรงานแฮก
- เกณฑ์ตัดสิน: impact 30%, ใช้ tool ของ Meta 25%, technical depth 20%, demo 25%
- รางวัลที่หนึ่งประมาณแสนกว่าเหรียญ จ่ายเงินสด ถ้าโอนเข้าไทยเสียภาษีราว 20-30%
- ได้เครดิต API ของมิวส์ (Muse Spark) ร้อยเหรียญรายคน ส่วน Baseten หรือ Fireworks ต้องเขียนโปรเจคไปขอ
- เวลาเดโมมีแค่ 3 นาที ต้องตัดวิดีโอให้กระชับและสนุก

### แนวทางสร้างไวฟบุ๊ค
- หัวใจคือ ง่าย และได้ผลลัพธ์ที่แชร์ต่อได้ ไม่ต้องเน้น engineering ให้ทำงานได้เต็มที่ เน้นเดโมและ feeling
- ใช้ REA (reverse engineer anything) เป็น tool ของเอเจนต์ เพื่อโคลนของจากภาพ คำอธิบาย และคอมเมนต์ในโพสต์
    - อาจต้องมีฟิลเตอร์คัดคอมเมนต์ที่ใช้ได้
- Facebook Graph API ช้า รอ public 1-2 week จึงพิจารณาม็อกโซเชียลมีเดีย หรือทำเป็น extension แทน
- ไอเดียเดโม: ไวฟจากโพสต์บน X แล้วแชร์บนเฟซบุ๊กตอนท้าย และต่อยอดไป Facebook Marketplace หรือมีมให้เพื่อนเล่นต่อ

### ขั้นตอนถัดไป
- (Speaker 1) ส่งสรุป transcript ของการประชุมให้ทีม แยกห้องไว้และแปะสรุปสั้นๆ
- (Speaker 2) อ่านและลองเล่น REA เพื่อดูว่าโคลนจากโพสต์ได้ดีพอไหม
- (Buddy Builds) เตรียมพรีเซนต์ไวฟบุ๊คให้คนดูเข้าใจและน่าสนใจ ให้เสร็จภายในวันที่สี่หรือเสาร์อาทิตย์นี้
- (ทุกคน) โยนแคมเปญที่น่าจะไวรัล (ภาพ วิดีโอ แอป เกม) ทั้งไทยและโกลบอลใส่ห้องรวม เพื่อคัด use case
